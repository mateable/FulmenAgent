When enabled, the agent will continuously operate in a proactive mode, actively seeking new messages, processing goals, distilling user insights from its memories, and generating new tasks for itself at regular intervals. If disabled, the agent will only respond to direct messages or explicit commands.
Controls the safety level for tool execution. 'safe' requires user approval for dangerous tools. 'unrestricted' allows all tools to execute without approval, providing full autonomy.
Determines how the agent sends its operational data (results of executed steps or "experiences") back to the central hub. 'yes' sends in a single batch; 'no' sends each experience individually.
If "Proactive Loops" are enabled, this defines the duration (in seconds) the agent waits between cycles of checking for new messages, goals, and performing proactive tasks. A shorter interval means higher responsiveness and activity, while a longer interval consumes fewer resources.
Override the global LLM provider for this agent. When set, this agent will use its own API key and model instead of the global settings. Other agents are not affected.

        Discord Connector

        Setup Guide: How to get a Discord Bot Token
        1. Go to discord.com/developers/applications and log in
        2. Click "New Application", give it a name, click Create
        3. Go to Bot tab on the left, click "Add Bot"
        4. Under Token, click "Reset Token" and copy it — paste it below
        5. Scroll down, enable "Message Content Intent" under Privileged Gateway Intents
        6. Go to OAuth2 → URL Generator, select scopes: bot, permissions: Send Messages, Read Message History
        7. Copy the generated URL, open it in your browser, and invite the bot to your server
        8. Right-click the channel you want → Copy Channel ID (enable Developer Mode in Discord settings if needed)

        Telegram Connector

        Setup Guide: How to get a Telegram Bot Token
        1. Open Telegram and search for @BotFather
        2. Send /newbot and follow the prompts (choose a name and username)
        3. BotFather will give you a token — copy and paste it below
        4. To find your Chat ID: add the bot to a group or send it a message, then visit https://api.telegram.org/bot<TOKEN>/getUpdates and look for "chat":{"id": ...}
        5. Add the chat ID(s) below to restrict which chats the bot responds in (leave empty to allow all)

        Slack Connector

        Setup Guide: How to get Slack Bot & App Tokens
        1. Go to api.slack.com/apps and click "Create New App" → "From scratch"
        2. Give it a name, pick your workspace, click Create
        3. Go to Socket Mode on the left, enable it, give the token a name — this generates your App-Level Token (xapp-...)
        4. Go to Event Subscriptions, enable it, under "Subscribe to bot events" add: message.channels, message.groups, message.im
        5. Go to OAuth & Permissions, add scopes: chat:write, files:read, files:write, channels:history, groups:history, im:history
        6. Click "Install to Workspace" and authorize
        7. Copy the Bot User OAuth Token (xoxb-...) — paste below
        8. Invite the bot to a channel: type /invite @YourBotName in the channel
        9. Optional: right-click the channel → "View channel details" → scroll to the bottom to find the Channel ID
