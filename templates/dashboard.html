When enabled, the agent will continuously operate in a proactive mode, actively seeking new messages, processing goals, distilling user insights from its memories, and generating new tasks for itself at regular intervals. If disabled, the agent will only respond to direct messages or explicit commands.
Controls the safety level for tool execution. 'safe' requires user approval for dangerous tools. 'unrestricted' allows all tools to execute without approval, providing full autonomy.
Determines how the agent sends its operational data (results of executed steps or "experiences") back to the central hub. 'yes' sends in a single batch; 'no' sends each experience individually.
If "Proactive Loops" are enabled, this defines the duration (in seconds) the agent waits between cycles of checking for new messages, goals, and performing proactive tasks. A shorter interval means higher responsiveness and activity, while a longer interval consumes fewer resources.
